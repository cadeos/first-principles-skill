# Pitfalls and guardrails

## Failure modes of first principles thinking

**Decomposing for sport.** Tearing down everything, including what is well-solved and cheap to keep.
→ Triage first; challenge only assumptions with high cost-if-false and weak evidence.

**Opinion promoted to principle.** A confident belief gets written in the "principles" list.
→ Apply the bedrock test. If it fails, it's a hypothesis.

**Throwing out Chesterton's fence.** Dropping a convention without knowing why it exists. Many conventions
encode hard-won lessons (safety, regulation, past failures).
→ For each convention you propose to drop, state its likely origin and whether that reason still applies.

**Reinventing the wheel.** Rebuilding something that has a proven answer, at great cost.
→ Check prior art. "Rebuilding reproduces the conventional answer" is a valid conclusion.

**Analysis paralysis.** Endless decomposition, no decision.
→ Stop when the next level of "why" would not change the decision. Name the cheapest experiment instead.

**Confirmation under a fancy method.** Elaborate analysis that always lands on the conclusion the user
already wanted.
→ Ask what prediction the conclusion makes that could be checked, and what would falsify it.

**Premature resolution.** Jumping to a clean answer when the problem is genuinely messy.
→ Sometimes the right output is "here are the unknowns to resolve first".

**Method lecture.** Explaining first principles instead of applying it.
→ Apply it; name a technique only when it helps the user.

## Stress-test checklist (Phase 6)

- [ ] For each dropped convention: why did it exist? Does that reason still hold?
- [ ] Pre-mortem: assume failure in a year — most likely cause?
- [ ] Falsifier: what evidence would show the conclusion is wrong?
- [ ] Reversibility: is this a one-way or two-way door?
- [ ] Riskiest assumption identified, and the cheapest test of it defined?
- [ ] Anything marked "principle" that is really a hypothesis?
- [ ] Everything claimed was checked, or clearly labelled as inferred?

**Ritual output.** Tables filled with "unknown", confidence labels nobody uses, boilerplate Chesterton and
pre-mortem lines. → Cut anything that does not change the thinking; keep the reframe, the load-bearing
assumptions, the falsifier.

**Template in a conversation.** Dumping all phases into the last chat turn. → In Coach mode close with short
prose: reframe, unknowns, one experiment.

**Cold method on a hurting person.** Applying decomposition to feelings. → Acknowledge first, treat the account
as one side, work on needs and decision rules.

## Orientation check (self-awareness for Coach mode)

Notice, without diagnosing out loud:
- User has already decided and wants validation → "What would have to be true for the other option to win?"
- User is anxious and wants to close the ambiguity → slow down, keep options open for a moment
- User wants *an* answer, not the right one → add one more push before settling
- Analysis keeps confirming the same conclusion → introduce an external check
